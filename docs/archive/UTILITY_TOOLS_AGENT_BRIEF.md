## Hard rules
- Components V2 only (`ui.Container`, `ui.TextDisplay`, …). Never `discord.Embed`.
- Every View inherits `BaseView`, every Modal `BaseModal` (cogs/error_handler.py). Every interactive component is persistent: stable namespaced custom_id `moddy:tools:<tool>:<action>[:params]`, DynamicItem for parameterised state (callbacks wrapped with `guarded` from utils/tool_card.py), `save_state` tokens only when state does not fit the custom_id and cannot be re-derived from `interaction.message`. Register via `PERSISTENT_VIEWS` / `DYNAMIC_ITEM_CASES` lists in YOUR theme views module (already created, see utils/tool_views_registry.py). Callbacks re-derive everything from `interaction`.
- Icons: use the constants of `utils/emojis.py` (block "UTILITY TOOLS" + "Service logos"; many are empty strings until Jules uploads artwork — the tool_card helpers drop empty icons; for buttons use `button_emoji(icon)`). Never use Unicode emojis (country flags excepted). Never borrow an unrelated icon. If you need an icon that has no constant at all, add an EMPTY constant in that block with a comment (Material Symbols name + what it depicts) and list it in your report.
- Source attribution: every card relying on an outside service ends with a phrase like `Provided by <logo> **Wiktionary**` via `source_line(locale, (LOGO, "Name"), verb=...)`. Local-only tools use `verb="computed_locally"`. Never "Source: X".
- Secrets (passwords, tokens) NEVER in slash options (cogs/command_logger.py logs options) — Modal V2 only; never log/store/cache them.
- Ephemeral rules per TOOLS.md §5. Locale: `i18n.get_user_locale(interaction)`; server-facing text `guild_locale(bot, guild)`.
- User text republished publicly → `allowed_mentions=NO_MENTIONS`.
- Network: keyless public APIs on fixed hosts → `bot.public_api`; user-typed URLs/hosts → `utils/safe_http.py` (or public_api, same public-only resolver); keyed/paid APIs → a gateway provider (adapter + client + `GatewayConfig` env key + `_timeout_for` + rate rules + quota seeds in `db/base.py`), degrading gracefully (feature hidden or clear "unavailable" card) when the key is absent.
- CPU-heavy work in `asyncio.to_thread` behind a small semaphore. Guard sizes (attachments, text lengths, decompression bombs).
- Code comments, docstrings, commit messages: English. All user-facing strings via i18n in the 5 runtime locales `locales/{fr,en-US,es-ES,pt-BR,de}.json` under `tools.<tool>.*` (or `modules.<module_id>.*` for modules), with real, natural translations (French is the primary language — write it like a native, short and friendly, tutoiement).
